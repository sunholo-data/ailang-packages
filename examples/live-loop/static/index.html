Take a loop into Live

Download WAV saves the active committed part, before its track level and pan. Each file is an eight-second mono loop at this session’s sample rate. Set Ableton Live to 120 BPM and check that it spans four bars. Private and scheduled takes are excluded.

Undo restores the previous committed part at the next loop boundary. Redo swaps it back. One previous version is kept per part, in memory for this session.
