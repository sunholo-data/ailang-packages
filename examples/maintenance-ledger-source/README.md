# Source-pinned maintenance ledger consumer

`sh check.sh` runs the independent 8-trajectory/24-stage economic instrument control using native AILANG from `../../packages/maintenance-bench`. Known deltas are controls, not language-advantage evidence. No registry fallback or model dispatch.

From this directory for adapter outputs:

```sh
ailang lock --check
ailang run --caps IO,FS,Env --entry main main.ail /absolute/plan.json /absolute/runs.json /absolute/usage.json EXTERNALLY_ATTESTED_COMPILER_ID /absolute/new-report.json
```

Freeze repository revision and dependency/module/lock/runtime digests outside the report before invocation. A lock mismatch fails explicitly. Source example only; no registry release.
