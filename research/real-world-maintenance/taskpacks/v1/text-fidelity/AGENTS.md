# Text-fidelity development assets

Read README.md and stages/contract.md before changing an asset. The initial
requirements/expected fixtures are independently specified development controls;
new protocols get a version and explicit amendment, never a silent rescore.
Keep starter sources free of future-stage solutions and mutants. Native AILANG
and Python implementations must retain equal responsibility. The Python host is
an external semantic oracle, not the AILANG implementation. Never accept a
compiler error, transport error or skipped oracle as a semantic negative control.
Run native check/tests/format and ./qualify.sh with a new output path after edits.
Frozen mature/pilot study directories and model execution are outside this scope.
