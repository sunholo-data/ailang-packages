# Real-requirement maintenance taskpacks v1

These are public development component adaptations of real production obligations. Both families have competent native AILANG/Python starters, three successive requests, native references, independent expected outputs and deliberate semantic controls. They are not existing language-development eval tasks or sealed confirmation cases.

- [Resource ownership](resource-ownership/README.md): inline/file migration, batch/byte cap and release/lifetime, seeded by Parse #46/#77.
- [Text fidelity](text-fidelity/README.md): preserve-space/ASCII edges, event interface migration and structured output, seeded by Calamine #671/#673.

`sh qualify.sh` runs both bounded native qualifiers and their host-oracle mutation tests. It creates only temporary output; a direct family `--output` must name a new file. Qualification does not execute a model or measure language productivity. The AILANG package analyses the resulting evidence; Python here is independent oracle/host glue.

Protocol amendment during initial qualification, before any model scoring: enforce JSON scalar types (Python bool/int equality cannot substitute for the typed protocol), refuse existing F1 output paths, and keep the F1 ordinary qualifier offline by running native compile/tests/smoke/SMT directly. Package quality remains a separately reported check that may attempt a registry overlap lookup. New qualification receipts bind the amended oracle/qualifier hashes; earlier worker receipts are historical development evidence.

Next: an existing-executor stage adapter must prove worker/oracle isolation and retain each agent's actual failed artifacts. Only then can a separately priced campaign produce real comparative model outcomes. Exposed controls stay in development; confirmation needs new real requirements frozen before execution.
