# Fixture provenance and independent expectations

`analytical.*` is a hand-specified **synthetic** arithmetic/partition fixture, never language-quality evidence. Ten source observations: nine eligible, eight mature, one censored and one excluded mirror. AILANG fixture: four mature changes, one linked escaped repair, two known defect/round identities, one CI interception. Python fixture: four mature changes, two linked escaped repairs, two defects/rounds. The unadjusted example delta is 100*(1/4-2/4) = -25 percentage points. A five-file repair is one defect. These expectations were specified before report execution; the expected file is not generated by the implementation.

`real_cases.*` contains four deliberately selected recent repairs, with public commit/PR references and exact canonical source paths inspected through local Git and gh. This is an incomplete discovery sample, not a representative cohort. Repairs are supported by source evidence, not independently reproduced here. AI authorship, introducing changes, detection time and defect linkage remain unknown. All changes lack 30-day follow-up at the fixed cutoff, so there is no mature-rate denominator. No claim about comparative bug rates follows from these cases. Do not upgrade supported to confirmed just to make a chart.

Git/gh collectors produce separately hashed raw response evidence; these curated rows are source-attributed case metadata, not raw-API snapshots. Full patches or private transcripts are not redistributed. Real and synthetic fixtures have visibly distinct source labels.
