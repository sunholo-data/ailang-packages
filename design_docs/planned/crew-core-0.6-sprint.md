# Sprint S-CREW-CORE-0.6: stand down at the check-in

**Design:** [crew-core-0.6-stand-down.md](crew-core-0.6-stand-down.md).

**Why:** Mark's ruling, attended 2026-10-16 ("a is fine"). At each auto-run
check-in (D-76 monthly), a crew member under strain may ask to stand down,
working or not. #149 measured 0 relief requests in a 10-year monthly
auto-run, because the game's work lasts 2–3 days and project agreements fall
due after 20.

**Base:** branch `fix/crew-core-0.5.1-checkin` (#149, crew_core 0.5.1,
unmerged). This sprint merges after it.

**Status:** awaiting Mark's approval. Nothing is implemented. The open
questions OQ1–OQ4 are at the end of the design doc. The plan assumes the
recommended answers, and a different answer changes only the milestones
named in the design.

**AILANG prompt version loaded:** v0.16.7 (runtime v0.54.11, the game's
pinned `stapledons-godot-attended/runtime/bin/ailang`).

**Registry reuse:** contribute. crew_core gains the verbs, and the game and
the lab both import them. No new package. `social_dynamics` 0.4.0 is a
dependency used unchanged: `halt`, `RaiseConcern`, `OfferTask` and
`OfferCommitment` already exist.
