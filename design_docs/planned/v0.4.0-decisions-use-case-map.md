**Goal**: every decision shape on `docs.typesafe.ai/concepts/use-case-map` has a first-class surface,

## Evidence (what the vendor docs say that v0.3.0 could not express)

- `primitives/advanced.md` — **EntryType**: `instructions` (all 3 types), Choice option values, Score
  level entries, and Noul `criteria.true/false` all accept `string | object | array | null`. v0.3.0
  emitted strings only and never sent Noul criteria. The hierarchical-classification pattern
  (option values = subtrees) and the SDE cascade (instructions carrying schema rows) were impossible.
- `api.md` — errors: 429/529 are retryable with exponential backoff; only 3 question types exist.
- `confidence.md` — confidence is derived from the distribution; Noul carries none; three-band
  act/caution/human pattern with risk-scaled, caller-owned thresholds.
- Patterns: fan-out (batching ~12× cheaper), confidence-gated routing, composite scoring
  (normalize each dimension to 0–1, weight with caller weights), intent routing.
- Cookbooks: rerank, `semantic_find` (218 line ids in one Choice), hierarchical classification
  (beam over Choice probabilities), LLM guardrails (Noul per hazard + Score severity), consistency
  (noul/choice), feature discovery (questions → numeric features → classical ML), pre-parsed value
  extraction, citation checking, entity alignment.

## Decisions taken (per the approval session)

1. **Single 0.4.0, kind = breaking.** The only breaking edge is exhaustive `match` on `Question`; every
   known consumer constructs questions (`lane_shadow.ail` matches with a wildcard). A staged
   feature-then-breaking pair would make consumers migrate twice.
2. Included optionals: `entropy`, `renormalise`, `retryable`/`retryAfterMs`, `listModelsDirect`.
3. Excluded (trim list): a three-band confidence helper (gate + caller ifs cover it — YAGNI) and
   `featuresJson` (the `[Feature]` records are the primitive).
4. `detect` is two-cut-point three-way; `gate` is untouched. D4 (no default thresholds) holds — every
   new threshold-taking helper requires the caller's cut points.
5. No auto-retry loop in-package: sleeping needs `Clock`, which would widen the effect ceiling —
   the classifier + a documented caller-side loop is the surface.

## Non-goals / guardrails held

No default thresholds · no free-text generation (System One doesn't generate; pre-parsed extraction is
a Choice-over-candidates recipe) · no synthesized Noul confidence · `[effects] max` unchanged · no
`std/ai` promotion (Phase 2, gated on the shadow measurement) · `decide*` signatures unchanged.

## Test + evidence plan

- 14 new native tests in `decide_test.ail` (33 total): R-question serialization (structured criteria,
  true/false noul criteria, no-criteria NoulR), schema equivalence, probabilityOf lookup/errors,
  best/ranked/topK/margin over the real fixtures, entropy bounds, renormalise projection/zero-sum,
  detect three-way + WrongVariant, compositeScore values + typed errors, featuresOf names/counts,
  noulSpread/choiceVotes across three banked bodies, retryable/retryAfterMs.
- `_smoke.ail` gains `smokeChecks()` (offline; executed by `ailang pkg quality`) including the
  R-fallback degradation, which lives in smoke rather than a `*_test.ail` for the harness reason
  recorded in CHANGELOG 0.2.0.
- Contracts: `detect`/`topK`/`retryAfterMs` have literal requires (Z3-friendly); `compositeScore`
  carries `ensures ∈ [0,1]` and `retryAfterMs` `ensures [1000, 30000]` — if Z3 cannot encode the list
  recursion these land as PUB016 runtime assertions (count them in the quality report; they are not
  proofs).
